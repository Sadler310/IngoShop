# ИнгоШоп — Каталог мерча СПАО «Ингосстрах»

Минималистичный веб-каталог сувенирной и подарочной продукции с возможностью выбора конфигураций (размеры, цвета), корзиной и формой заявки на поставку.

## Особенности проекта
- **Фирменный стиль:** Официальный цвет Ингосстраха (`#002F6C`), сдержанная типографика на шрифте Inter.
- **Адаптивность:** Бургер-меню для мобильных устройств, горизонтальные теги категорий, всплывающие окна и drawer-корзина.
- **Автономность:** Работает без этапа сборки (Zero-build), можно развернуть на GitHub Pages и Vercel из коробки.
- **Локальное сохранение:** Корзина синхронизируется в `localStorage`.

## Запуск локально
Просто откройте `index.html` в любом современном браузере.
